# Trash Dash!

เกมแยกขยะ Top-down 3D สไตล์ปาร์ตี้ เล่นในเว็บเบราว์เซอร์ วิ่งเก็บขยะ กลับฐาน ทิ้งให้ถูกสี และแย่งของคะแนนสูงให้ทัน!

**Trash Dash เป็นโปรเจกต์เกมแยกต่างหากจาก Click to Save the Planet** repository นี้มีเฉพาะ Trash Dash

## เวอร์ชัน 0.1.0

- ตัวละคร 3D หมวกสัตว์ พร้อมท่ายืน วิ่ง ถือของ พุ่ง และดีใจ
- ควบคุมผู้เล่นของตัวเองหนึ่งคนต่อหน้าจอ พร้อมบอตคู่แข่ง 3 ตัวที่เลือกเปิด/ปิดได้
- ฐาน 4 มุม ถังส่วนตัวมุมละ 4 สี พร้อมไฮไลต์ถังที่กำลังเล็ง
- แผงใหญ่ทางซ้ายแสดงขยะที่ถือ ประเภท คะแนนพื้นฐาน และคะแนนที่จะได้รับจริง
- 5 Wave เวฟละ 18 วินาที ขยะทยอยเกิดทีละชิ้น รวมรอบละ 90 วินาที
- คะแนนรายชิ้น 10 / 15 / 20 / 30 / 50 ของคะแนนสูงมีวงแสง ประกาย และลำแสงทอง
- คอมโบ พุ่งชน คะแนนคูณสองช่วงท้าย พักเกม และสรุปอันดับ
- รองรับคีย์บอร์ด ปุ่มสัมผัส และจอยเกมแบบ standard mapping
- UI แยกสนาม คะแนน แผงซ้าย และปุ่มควบคุมออกจากกัน ข้อความ Wave และแจ้งเตือนอยู่ในแผงซ้าย

**ยังไม่มีระบบออนไลน์** เวอร์ชันนี้เป็น prototype สำหรับเล่นคนเดียว/แข่งกับบอต ระบบเครือข่ายจะพัฒนาภายหลัง

## เปิดเล่นในเครื่อง

### Windows

ดับเบิลคลิก `RUN_GAME.cmd` แล้วเปิด http://127.0.0.1:8080/ เก็บหน้าต่างเซิร์ฟเวอร์ไว้ระหว่างเล่น

### Node.js 22 ขึ้นไป

```sh
npm start
```

ไม่ต้อง `npm install` เพราะไม่มี package dependencies ที่ต้องติดตั้ง เปิดผ่าน HTTP ไม่ใช่ดับเบิลคลิก `index.html` เนื่องจากใช้ JavaScript modules

## ปุ่มควบคุม

- **WASD** เดิน
- **E** เก็บ / ทิ้ง ถือได้ครั้งละหนึ่งชิ้น ทิ้งได้เฉพาะฐาน P1 ของตัวเอง
- **Shift** พุ่ง มีคูลดาวน์ 2.1 วินาที
- **Esc** พักเกม
- **จอยเกม** สติ๊กซ้าย / D-pad เดิน, A เก็บ/ทิ้ง, B พุ่ง
- **หน้าจอสัมผัส** ใช้จอยด้านล่างและปุ่มเก็บ/ทิ้ง

## ถังขยะและคะแนน

- **สีฟ้า — ทั่วไป:** ซองขนม ทิชชู่ใช้แล้ว กล่องโฟม — 10 คะแนน
- **สีแดง — อันตราย:** ถ่านไฟฉาย 30 คะแนน, มือถือเก่า 50 คะแนน
- **สีเหลือง — รีไซเคิล:** กระป๋อง 15 คะแนน, ขวดพลาสติกและกระดาษสะอาด 20 คะแนน
- **สีเขียว — ขยะเปียก:** แกนแอปเปิล 10 คะแนน, เปลือกกล้วยและเศษอาหาร 15 คะแนน

ทิ้งถูกต่อเนื่องเพิ่มคอมโบครั้งละ 2 สูงสุด +10 ต่อชิ้น 15 วินาทีสุดท้ายคูณสองทั้งคะแนนพื้นฐานและคอมโบ ทิ้งผิด −5 คะแนน คอมโบหาย และยังถือชิ้นเดิมอยู่ คะแนนต่ำสุด 0

## Wave

1. อุ่นเครื่อง — 8 ชิ้น ทีละ 1.6 วินาที ปิดด้วยของ 20 คะแนน
2. เริ่มคึกคัก — 10 ชิ้น ทีละ 1.4 วินาที ปิดด้วยของ 30 คะแนน
3. ของหายากมาแล้ว — 12 ชิ้น ทีละ 1.2 วินาที ปิดด้วยของ 50 คะแนน
4. แย่งกันให้ไว — 14 ชิ้น ทีละ 1.05 วินาที ปิดด้วยของ 50 คะแนน
5. ปาร์ตี้ส่งท้าย — 16 ชิ้น ทีละ 0.9 วินาที ปิดด้วยของ 50 คะแนน

ขยะที่วางบนพื้นจะหายหลัง 34 วินาทีเพื่อเปิดพื้นที่ให้เวฟใหม่ ขยะในมือไม่หาย

## เทคโนโลยี

HTML / CSS / JavaScript และ Three.js 0.170.0 โมเดลและแอนิเมชันสร้างด้วยโค้ด รองรับ WebGL 2 Three.js เก็บไว้ใน `party/vendor/` พร้อม MIT license ไม่พึ่ง CDN ระหว่างเล่น ฟอนต์ Google Fonts เป็นตัวเลือกและมีฟอนต์ระบบสำรอง

ไฟล์ `index.html` และโฟลเดอร์ `party/` สามารถนำไปวางบน static hosting ที่รองรับ JavaScript modules ได้
